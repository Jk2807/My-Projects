## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Jk2807/My-Projects.git
cd My-Projects
```

### C
```bash
gcc filename.c -o app
./app
```

### C++
```bash
g++ filename.cpp -o app
./app
```

### Python
```bash
python filename.py
```

### MATLAB
Run `.m` files directly in MATLAB (Editor or Command Window).
