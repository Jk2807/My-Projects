# Application of the FFT - Noise Filtering

## Overview

This project explores the **theory and practical applications of the Fast Fourier Transform (FFT)** in Digital Signal Processing (DSP).  
It was developed as part of a **DSP module project** and demonstrates how frequency-domain analysis can be used to solve real-world signal problems.

The work focuses on two practical FFT-based applications:

- **Heartbeat sensing** (frequency-domain interpretation of periodic biological signals), and
- **Audio noise filtering** (removal/reduction of unwanted frequency components).

A MATLAB script is included to visualize and evaluate the effectiveness of FFT-based processing.

## Project Information

- **Project Name:** Application of the FFT - Noise filtering  
- **Duration:** April 2025 – June 2025  
- **Type:** Module Project (Digital Signal Processing)  
- **Role:** Programmer and demonstrator of Application 1  
- **Inspiration / Learning Source:** FFT theory and applied DSP study materials

## Objectives

- Research the **Fast Fourier Transform** from both theoretical and practical perspectives.
- Implement and demonstrate FFT-based signal analysis in MATLAB.
- Show at least two real use cases of FFT:
  - heartbeat sensing, and
  - audio noise filtering.
- Visualize before/after effects to evaluate filtering performance.

## Key Concepts Used

- **FFT (Fast Fourier Transform)**
- **Inverse FFT (IFFT)**
- **Frequency-domain signal analysis**
- **Noise component identification**
- **Digital filtering workflow**
- **MATLAB-based data visualization**

## Features

- MATLAB implementation of FFT signal transformation and analysis.
- Demonstration of FFT application in physiological signal interpretation (heartbeat sensing).
- Demonstration of FFT-based audio denoising by suppressing selected frequency bands.
- Visualization of original and processed signals/spectra for comparison.
- Educational structure suitable for DSP learning and demonstration.

## Tools and Environment

- **MATLAB**  
- Core numerical and signal-processing functions for FFT/IFFT and plotting.
