# Simulation and Evaluation of OFDM MIMO System Using MATLAB

## Overview
This project presents the **simulation and evaluation of a 2×2 MIMO-OFDM communication system** in MATLAB.  
It was developed as part of the **Mobile Communication** class project and applies core concepts from **Digital Signal Processing (DSP)** and **wireless communication systems**.

The implementation demonstrates the end-to-end communication chain with step-by-step behavior of:
- data encoding,
- OFDM transmission through a MIMO channel, and
- receiver-side decoding and signal recovery.

A modified version of the program is also included to highlight flexibility for **parameter analysis** and experimentation.

## Project Information
- **Project Name:** Simulation and evaluation of OFDM MIMO system using Matlab  
- **Duration:** November 2025 – February 2026  
- **Type:** Class Project (Mobile Communication)  
- **Role:** Leader, Programmer  
- **Inspiration / Learning Source:** *“OFDM Fundamentals & Applications” – Waveform Academy*

## Objectives
- Apply theoretical understanding of mobile communication in a practical simulation.
- Build a MATLAB model of a **2×2 MIMO OFDM system**.
- Visualize processing stages to improve conceptual understanding.
- Enable easy modification of system parameters for comparative analysis.

## Key Concepts Used
- **OFDM (Orthogonal Frequency Division Multiplexing)**
- **2×2 MIMO (Multiple-Input Multiple-Output)**
- **QAM Modulation**
- **FFT / IFFT (Fast Fourier Transform / Inverse FFT)**
- **Matrix-based signal processing**

## Features
- Step-by-step simulation of transmitter and receiver flow.
- Visualization-friendly structure for learning and demonstration.
- Modular logic that allows adaptation to different communication parameters.
- Additional modified script for experimentation and parameter sensitivity studies.

## Tools and Environment
- **MATLAB**  
- Built using foundational numerical and signal-processing operations.

## Learning Outcome
This project strengthened practical understanding of how modern wireless systems combine OFDM and MIMO techniques to improve spectral efficiency and communication reliability, while also reinforcing MATLAB implementation skills for communication system prototyping.

## Notes
This repository includes the original and a modified implementation to show how the model can be reused as an educational and analytical tool.
