# Electrical Components Classification & Identification


## Overview

This project presents the **design and implementation of a real-time electrical component detection and classification system** using **ESP32-CAM** and **Edge Impulse**.  
It was developed as part of an **Object-Oriented Programming** module project and combines concepts from **embedded systems**, **computer vision**, and **AI-based edge inference**.

The implementation demonstrates a complete workflow that includes:

- real-time image capture and component recognition,
- classification-driven inventory logic, and
- object-oriented management of storage, updates, and checkout operations.

The system is designed as an edge-based solution, enabling lightweight and efficient inventory tracking without relying heavily on cloud-side processing.


## Project Information

- **Project Name:** Electrical Components Classification & Identification  
- **Duration:** September 2024 – January 2025  
- **Type:** Module Project (Object-Oriented Programming)  
- **Role:** Leader, Classification model deployment, Coder  
- **Inspiration / Learning Sources:** ESP32-CAM embedded vision workflows, Edge Impulse edge AI pipeline


## Objectives

- Build a practical embedded AI solution for identifying electrical components in real time.
- Apply object-oriented programming principles to organize inventory operations.
- Integrate model inference with device-side system logic for low-latency results.
- Develop a reusable framework for smart inventory tracking in electronics-focused environments.


## Key Concepts Used

- **Edge AI / TinyML** with Edge Impulse  
- **ESP32-CAM** for real-time image acquisition  
- **Object-Oriented Programming (C++)**  
- **Embedded systems integration**  
- **Inventory and checkout management logic**


## Features

- Real-time component detection and classification on edge hardware.
- On-device classification inference pipeline integrated with embedded firmware.
- C++ OOP-based modules for:
  - storage management,
  - inventory updates, and
  - checkout functionality.
- Practical AI + embedded system architecture for inventory automation.


## System Workflow

1. Capture component image using ESP32-CAM.  
2. Run classification model inference (Edge Impulse deployment).  
3. Identify component category/class in real time.  
4. Update inventory records through OOP-based management modules.  
5. Support checkout and stock tracking operations.


## Tools and Environment

- **ESP32-CAM**
- **Edge Impulse**
- **C++ (Object-Oriented Programming)**
- Embedded development toolchain (board-specific firmware setup)
